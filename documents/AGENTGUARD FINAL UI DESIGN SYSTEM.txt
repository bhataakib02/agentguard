🎨 AGENTGUARD — FINAL UI DESIGN SYSTEM

1. Overall Design Direction

Style: Modern + Minimal + Premium + Enterprise + AI

Think:

Apple-like cleanliness + modern SaaS dashboard + trustworthy AI governance

Main characteristics

White/off-white backgrounds

Very light borders

Rounded cards

Soft shadows

Large whitespace

Times New Roman typography

Dark charcoal text

Green as the primary action color

Orange/yellow for attention

Red only for dangerous situations

Purple/blue for AI/intelligence elements

Small fruit/botanical visual accents

No excessive gradients

No excessive colors

No dark dashboard as the primary theme

#F59A23

visual language.

🌓 31. DARK MODE

For your first version, I recommend:

The light theme you've selected is much more distinctive and easier to keep visually consistent.

You can add dark mode later.
