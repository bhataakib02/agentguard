AGENTGUARD — SYNTHETIC 5-ORGANIZATION DATASET

Exactly 5 organizations are included.
Each organization has 8 human roles:
USER, VIEWER, ANALYST, OPERATOR, SECURITY_ANALYST, MANAGER, DEVELOPER, ADMIN.

Each organization also has 5 AI agents using IAM role AGENT, plus passports,
capability tokens, policies, governance decisions, approval requests,
security events, audit logs, notifications and one license.

SUPER_ADMIN is intentionally NOT included as a tenant user.
All values are synthetic demo data.

This package contains CSV/JSON data and is NOT guaranteed to match your exact
SQLAlchemy/Supabase column names. Inspect the existing AGENTGUARD schema before
importing. Do not use these files to bypass Supabase Auth.
