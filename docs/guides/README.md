# AGENTGUARD Developer & Operator Guides

Welcome to the AGENTGUARD Guides directory. These technical guides provide step-by-step instructions for installing, configuring, integrating, and testing the AGENTGUARD AI Runtime Control Plane.

---

## 1. Directory of Guides

1. [Local Setup Guide](LOCAL_SETUP.md): Step-by-step local installation and environment setup for developers and evaluators.
2. [Configuration Guide](CONFIGURATION.md): Comprehensive reference for all environment variables, security keys, database URIs, and Redis configurations.
3. [API Guide](API_GUIDE.md): Complete REST & WebSocket API reference for authentication, agent registration, PACE evaluation, policy management, and telemetry.
4. [SDK Integration Guide](SDK_GUIDE.md): Integration guide for the official Python (`agentguard`) and TypeScript (`@agentguard/sdk`) SDKs with LangChain, CrewAI, and direct HTTP clients.
5. [Testing & Verification Guide](TESTING_GUIDE.md): Guide to running backend regression test suites, frontend verification, SDK tests, and automated quality checks.
